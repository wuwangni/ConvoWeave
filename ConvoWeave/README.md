# ConvoWeave

把 ChatGPT 的长对话，变成一份可点击的提问目录。

右侧悬浮一张卡片，自动列出当前对话里你发过的每一条提问；点一下就能平滑跳到对应位置并高亮它。
滚动时目录跟着你走，还能搜索过滤、收起成一列短横线，并且能把「选中某段话继续追问」产生的子提问
按父子关系排好。

纯原生 JavaScript，**零构建、零框架、零依赖** —— 下载下来直接就能加载运行。

> 这个仓库是**跟着教程手写出来的实现版**，代码注释按章保留，适合拿来读。

---

## 功能

- **提问目录** — 自动提取当前对话里的全部用户提问，按时间顺序列出，新消息自动进目录
- **点击跳转** — 平滑滚动到该提问，并叠一圈脉冲高亮（1.7s 后淡出，不改动页面结构）
- **阅读位置同步** — 滚动页面时自动高亮"你正读到哪一条"
- **短标题** — 清洗 markdown 记号后截取前 N 字，标题永远是原文的前缀，不做语义改写
- **搜索过滤** — 输入即过滤；子提问命中时，它的父提问会一起显示
- **悬停看全文** — 标题被截断时，鼠标悬停浮出完整原文
- **收起态** — 收起后只在右侧留一列短横线，鼠标扫过自动展开
- **目录全量加载** — 超长对话也完整：ChatGPT 只渲染视口附近的消息，插件走同源接口把整个会话取回来
- **父子提问两级目录** — "选中一段话再提问"生成的子提问，缩进排在**它真正所属的父提问**下面
- **回到刚才** — 点击子提问顶部的「← 回到刚才」，精确滚回当初选中的那段原文并高亮它

## 安装

1. 打开 `chrome://extensions/`（Edge 用 `edge://extensions/`）
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择**本仓库根目录**（含 `manifest.json` 的那一层）
4. 打开或刷新 `https://chatgpt.com/` 的任意对话，右侧就会出现导航卡片

> 改完代码后必须**先在扩展页点 ⟳ 重载，再刷新 ChatGPT 页面**，顺序反了不生效。

## 使用

| 操作 | 效果 |
| --- | --- |
| 点击条目 | 跳到该提问并高亮 |
| 滚动页面 | 目录自动跟随当前阅读位置 |
| 点搜索按钮 | 展开搜索框，输入即过滤，`Esc` 清空 |
| 点收起按钮 | 收成一列短横线，鼠标扫过自动展开 |
| 悬停被截断的条目 | 左侧浮出完整提问 |
| 选中 AI 回答里的一段 → 提问 | 生成子提问，自动归到父提问下面 |
| 点子提问顶部的「← 回到刚才」 | 滚回当初选中的那段原文并高亮 |

## 项目结构

```
ConvoWeave/
├── manifest.json      MV3 清单：只申请 storage 权限，只注入 chatgpt.com
├── parser.js          页面解析：提取提问、找滚动容器、跳转落位、片段定位与高亮
├── summarizer.js      标题压缩：清洗 + 截前 N 字（纯函数，不认识 DOM）
├── history.js         目录全量加载：同源接口取整个会话（拿不到就退回页面）
├── sidebar.js         面板 UI：渲染、收起、搜索、悬停气泡、"回到刚才"栏
├── content.js         主控制器：串流程、滚动同步、会话切换
└── style.css          全部样式
```

### 命名约定

所有标识统一用 `cw` 打头 —— class `cw-`、CSS 变量 `--cw-`、JS 全局 `CW_`、存储 key `cw:`、日志 `[CW]`。
这不只是为了好看：ChatGPT 页面自己的元素永远不会叫 `cw-xxx`，我们的选择器和样式在物理上
不可能误伤页面元素。

## 已知限制

- **只适配 ChatGPT**（`chatgpt.com` / `chat.openai.com`）。换别的站点需要改 `parser.js` 里的选择器。
- **依赖 OpenAI 当前的 DOM 结构**，官方改版后选择器需要跟着更新。
- 页面处于全屏遮罩或弹窗时，面板可能被盖住，可以先收起。
